
# ResolveAI

An AI-powered customer support platform built with
Python, Django and MySQL.

## Project Status
In active development.

## Implemented Features
- Customer support ticket model
- MySQL database integration
- Django Admin ticket management
- Support dashboard
- Ticket status and priority tracking

## Planned AI Features
- NLP-based ticket classification
- Sentiment and urgency detection
- Semantic knowledge-base retrieval
- AI-generated response suggestions
- Human approval and escalation
- Support analytics

## Technologies
- Python
- Django
- MySQL
- Bootstrap

## Local Setup
1. Create a Python virtual environment.
2. Install dependencies using requirements.txt.
3. Configure environment variables in .env.
4. Create a MySQL database and user.
5. Run Django migrations.
6. Start the development server.

## Current Development Goal
Build and evaluate an NLP-powered customer
support workflow.
